# Images to add before publishing

Drop these six PNG files into this folder (`docs/assets/images/`), then delete this file.

| Filename | Used on | Suggested size |
|---|---|---|
| `profile.png` | Homepage headshot (shown as a circle) | 300 x 300 px, square |
| `about.png` | Homepage "About Me" section | max 500 px wide |
| `offset-adaptation-cover.png` | Signal offsets project card | 800 x 450 px (16:9) |
| `iitb-campus-traffic-cover.png` | Campus traffic project card | 800 x 450 px (16:9) |
| `soil-pile-cover.png` | Soil-pile project card | 800 x 450 px (16:9) |
| `hostel-building-cover.png` | Hostel building project card | 800 x 450 px (16:9) |

Keep every file well under 500 KB — they load on every visit.
Cover images work best as landscape screenshots of the actual work: a VISSIM
network view, a QGIS map of the campus segment, a STAAD.Pro model, a
reinforcement drawing.
